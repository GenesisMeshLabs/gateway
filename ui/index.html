Onboard another operator

Confirm the sovereign name and authority public key independently. Run the native genesis-mesh-operator preflight against its HTTPS origin, then review the generated policy fragment. Resolve expired delegations with the owning operator before onboarding.

genesis-mesh-operator --origin https://na.example.org --network example --authority-key BASE64_PUBLIC_KEY --report preflight.json --policy-fragment network.json

A gateway connection does not create recognition. Establish scoped treaties, verify a test membership, revoke it, and confirm rejection at every peer after propagation. External operator adoption and full protocol conformance require separate evidence.
